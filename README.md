# Ledgerly

Ledgerly is a small capital call reconciliation app. Django REST Framework owns the API and matching rules; the React page uploads bank statements and lets a GP review proposed matches.

## Project layout

- `backend/` — Django API, models, seed command, and tests
- `frontend/` — React single-page app
- `ASSESSMENT_NOTES.md` — setup, data model, API, assumptions, and handoff notes

See `ASSESSMENT_NOTES.md` for setup instructions.
